# 配音、字幕与猫咪动画

《小鱼饼失踪案》是原创的双角色猫咪动画：橘子发现小鱼饼不见了，团团帮它找线索，最后发现早餐是橘子自己藏起来忘了。十二个镜头，每个约五秒。

参考了 [Simon’s Cat 官方短片列表](https://www.simonscat.com/watch) 中食物与纸箱等日常小冲突的选题简介。角色、对白、剧情和画面均为本项目原创，没有使用现有视频片段。

## 生成一条完整短片

1. 启动根目录 `start-comfyui-gpu.cmd`，等待本地服务 `http://127.0.0.1:8189` 就绪。
2. 确保当前用户已配置 `MIMO_API_KEY` 环境变量。
3. 双击 `generate-cat-comic.cmd`，它会创建新的批次，生成画面，再合成配音和字幕。
4. 成片位于 `runs/<批次>/final/film_with_dialogue.mp4`。

也可分阶段运行。在项目根目录 PowerShell 中执行：

```powershell
& .\ComfyUI\.venv-rocm\Scripts\python.exe -u services\media\produce_video.py --config config\cat_comic_video.json --storyboard prompts\stories\cat_biscuit_mystery.json --run-id my_cat_comic_001
& .\ComfyUI\.venv-rocm\Scripts\python.exe -u services\media\add_dialogue.py --run-dir runs\my_cat_comic_001
```

画面生成脚本使用本地 Wan 2.2 5B，配音脚本调用 MiMo 云端 API。基础 Python 依赖已安装，不需要另外安装 FFmpeg 命令行工具。本机配音脚本优先读取进程环境变量，读取不到时从 Windows 当前用户环境变量读取；密钥不会写入配置、工作流或生成日志。

## 文件与目录

| 文件或目录 | 用途 |
| --- | --- |
| `config/cat_comic_video.json` | 480×832、24fps、121 帧、20 步；每段拼接时保留前 120 帧，十二段正好 60 秒。 |
| `config/mimo_tts.json` | MiMo API 地址、模型、采样率和字幕字体配置；不包含密钥。 |
| `prompts/stories/cat_biscuit_mystery.json` | 分镜、两位角色、英文画面提示词、中文对白和音色风格。 |
| `prompts/assets/` | 用内置 imagegen 制作的四张角色与关键场景参考图。 |
| `prompts/assets/cat_biscuit_image_prompts.json` | 参考图生成方式、初始提示词、修改时的共同约束与各场景提示词。 |
| `services/media/add_dialogue.py` | 逐句生成配音、创建音轨和字幕时间轴、合成最终 MP4。 |
| `runs/<批次>/audio/` | MiMo 原始 WAV、处理后的每句 WAV、整条音轨和配音记录。 |
| `runs/<批次>/subtitles/` | UTF-8 SRT 字幕与 JSON 时间轴。 |
| `runs/<批次>/final/film.mp4` | 拼接好的无声画面。 |
| `runs/<批次>/final/film_with_dialogue.mp4` | 带 AAC 配音与烧录中文字幕的最终成片。 |

## 对白与字幕

分镜可设置 `dialogue` 列表，每句填写 `speaker` 和 `text`。顶层 `speakers` 给每位角色设置 `voice` 与 `style`。本片橘子使用 `苏打`，团团使用 `茉莉`，均为 MiMo 预置音色。

字幕来自明确的对白文本，按每句实际生成的音频时长安排；仅裁掉音频首尾静音，必要时在 1.3 倍以内进行不改变音高的调速。超过镜头可容纳时长的长对白会报错，需缩短文本。字幕为逐句同步，不提供逐字高亮。

成片底部保留 160 像素的统一字幕栏，显示标题和角色对白，也覆盖模型偶尔生成的底部伪文字。参考图与镜头构图为字幕区域留出了空间。

当前是双角色配音动画，画面动作由 Wan 生成，嘴型不保证与对白严格同步。没有加入背景音乐。

## 复用与修稿

相同批次和相同输入重跑时，成功镜头和配音会复用。配音可独立于画面处理，无需重生成视频：

```powershell
& .\ComfyUI\.venv-rocm\Scripts\python.exe -u services\media\add_dialogue.py --run-dir runs\my_cat_comic_001 --audio-only
```

单句重配可加 `--regenerate-lines 12`。可选的 `--style-override` 调整所选句子的朗读风格。旧音频和元数据会归档在该批次中。

修改对白时，可提供一个 JSON 文件，例如 `{"12": "下次，记得先问问自己！"}`，然后同时传入 `--dialogue-overrides <文件>` 和 `--regenerate-lines 12`。修改会保存为 `audio/dialogue_overrides.json`，以后重跑沿用它；分镜原始快照仍保留。
