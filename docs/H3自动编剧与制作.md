# H3 自动编剧与制作

当前操作台使用本机 H3 INT8 ConvRot，视频与声音一同生成。两套 Wan 权重及专用编码器、VAE 已按用户要求移除，释放约 29.2 GB。原有剧本、历史视频与旧参数保留；旧 Wan 批次需要重新安装相应模型才能重做。

## 操作

打开 http://127.0.0.1:8190，创建作品，在「剧本与角色」点击「自动编剧与分镜」。填写人物、情节、时长、画面风格等要求；默认先产出可修改的剧本。勾选「规划完成后自动生成」可继续生成和合成。

可以在二级制作台修改角色外观、分镜、摄影指令和对白。H3 默认 768×448、24fps，每镜保留 120 帧即 5 秒。模型实际生成 124 帧，拼接时裁到 120 帧。H3 对白属于生成提示词，修改对白会重新生成该镜头的画面与声音。

文本编码默认使用 ComfyUI 的自动 GPU 卸载，按显存容量在显存和内存之间调度。该模式已在 RX 9070 XT 16GB 上实际进入采样；CPU 编码作为可选回退，长提示词耗时明显更长。

中文的场景说明、摄影指令和角色外观会通过 MiMo 转换为英文视觉指令，转换结果保存在每镜的 `prompts/shot_XX_direction.json` 中并复用。提交 H3 的提示词只在对白标签里保留中文，避免模型把导演说明朗读出来。操作台中的中文说明仍可以编辑。

自动规划以首镜作为人物和场景参考，后续镜头采用同一个参考图，参考图来自首镜最后一帧。它有助于保持人物和服装一致，但不能保证每帧完全一致。修改首镜后，正常全片生成会更新依赖它的镜头；「仅重做一个镜头」保留其余镜头便于比较。

## 两个项目的接入范围

- [Script-Weaver](https://github.com/KKenny0/script-weaver)：运行真实 PipelineEngine，依次生成创意、纲要、角色、场景、美术、剧本、分镜。随后转换为 AIMedia 可编辑结构，检查反转因果和对白长度。
- [VideoClaw](https://github.com/HITsz-TMG/VideoClaw)：复用其现行 `staging_continuity_zh.txt` 连续性审查规则，检查站位、视线、物件与空间关系，并把修订写回分镜及生成提示词。未启动 VideoClaw 独立网站或其云端视频服务。

规划使用已经配置的 MiMo `mimo-v2.5-pro` 官方文本接口；API Key 只从环境变量读取。视频生成在本机 H3 上执行。配置文件和规划档案不保存 Key。

源代码安装在 `.runtime/integrations/`，固定提交记录在 `sources.json`。重新安装源代码可运行 `services/media/install_planners.py`，Script-Weaver 还需安装到运行操作台的 Python 环境。当前已安装到 ComfyUI 的 ROCm 虚拟环境。

另一台机器拉取代码后，先按本机硬件安装 ComfyUI、GPU 环境和 H3 权重，再在操作台的 Python 环境内安装依赖与规划源码：

```powershell
python -m pip install -r services/studio/requirements.txt
python services/media/install_planners.py
python -m pip install -e .runtime/integrations/script-weaver
```

以上 `python` 指运行操作台的同一个 Python。若 GPU 虚拟环境没有 pip，可使用已有 pip 的 Python 执行 `python -m pip --python ComfyUI/.venv-rocm/Scripts/python.exe install ...`。配置 `MIMO_API_KEY` 环境变量后运行 `start-studio.cmd`；该启动器使用项目内的 `ComfyUI/.venv-rocm/Scripts/python.exe`。模型、虚拟环境、`workspace/` 和 `runs/` 不随 Git 上传。当前字幕字体路径适用于 Windows。

## 保存位置

| 路径 | 内容 |
| --- | --- |
| `config/planning.json` | 规划模型、官方接口和请求参数，不含密钥 |
| `config/h3_studio_video.json` | H3 操作台默认视频参数 |
| `workspace/projects/<作品ID>/` | 草稿与修改历史 |
| `runs/<批次>/planning/` | Script-Weaver 检查点、完整输出、剧情终审、VideoClaw 审查与最终分镜 |
| `runs/<批次>/clips/` | 每镜头 H3 视频，包含原生声音 |
| `runs/<批次>/references/` | 各镜头参考帧 |
| `runs/<批次>/prompts/` | H3 工作流与英文导演指令缓存 |
| `runs/<批次>/subtitles/` | 中文字幕与时间轴 |
| `runs/<批次>/final/film_with_dialogue.mp4` | 带原生声音和烧录字幕的成片 |

字幕初始时间按五秒镜头内的对白区间安排，并非自动语音强制对齐。H3 实际发音可能与提示词有偏差；交付前需要检查对白和字幕，必要时重做镜头或修正时间轴。

规划会逐阶段保存检查点。中断后可继续任务；若规划过程中手动修改草稿，规划结果保存在本批次，避免覆盖新草稿。
