# 一分钟猫咪动画验收

日期：2026-10-04。标题：《小鱼饼失踪案》。批次：`20261004_cat_biscuit_mystery_001`。

橘子发现早餐不见了，团团陪它寻找线索，最后发现小鱼饼是橘子自己藏起来忘了。两只小猫分享早餐结束故事。参考了 [Simon’s Cat 官方短片列表](https://www.simonscat.com/watch) 中食物与纸箱等日常冲突的选题简介；未使用其视频片段，角色、画面、剧情和对白均为原创。

## 产物

- 最终 MP4：`runs/20261004_cat_biscuit_mystery_001/final/film_with_dialogue.mp4`。
- 无声拼接版：同批次 `final/film.mp4`。
- 中文剧本与分镜：同批次 `script.md`、`storyboard.json`。
- 十二段视频：同批次 `clips/shot_01.mp4` 至 `shot_12.mp4`。
- 配音：同批次 `audio/dialogue.wav`、逐句原始及处理后的 WAV、`audio/manifest.json`。
- 独立字幕：同批次 `subtitles/dialogue.srt`、`subtitles/timeline.json`。
- 技术验证：同批次 `logs/final_validation.json`；十二张字幕画面抽查图位于 `logs/qa/`。

## 实测

| 项目 | 结果 |
| --- | --- |
| 本地视频模型与硬件 | Wan 2.2 TI2V 5B，RX 9070 XT 16GB，Windows ROCm 10 |
| 单段生成 | 480×832、24fps、121 帧、20 步 |
| 最终画面 | 每段保留前 120 帧；1440 帧，60.000 秒，H.264 |
| 配音 | MiMo `mimo-v2.5-tts`，橘子使用苏打，团团使用茉莉，十二句中文对白 |
| 最终音轨 | AAC，单声道，24kHz；完整解码得到 60.000 秒 |
| 字幕 | 十二条按实际音频时长安排的中文对白，烧录进画面，同时保存 UTF-8 SRT |
| 文件大小 | 10,046,746 字节 |
| 常规单段耗时 | 约 245～250 秒 |
| 本次画面阶段耗时 | 首次提交至最后一段收集完成约 52.88 分钟，包含调稿和恢复执行 |
| 成片 SHA256 | `35ec002cf26a7ac50f475330dca135b11dc523a922f85c990cea5cd37c8d76ff` |

完整解码最终视频和音轨，验证帧数、时长、音视频时间戳连续递增、每句对白均有实际声音、字幕时间不超出所属镜头及成片校验值。AAC 解码音轨与原始合成音轨相关系数约 0.99964，峰值约 0.966，没有削波。整条配音通过 MiMo ASR 复核，忽略标点后与十二句对白完全一致，记录位于 `logs/dialogue_final_transcription.json`。

逐镜头检查了成片对白期间的截图，中文字幕清晰，角色及场景能够延续。早期几个镜头的底部出现模型生成的伪文字，最终以统一的 160 像素字幕栏覆盖。第 1、5、9、11 段使用干净的关键场景参考图，其余延续上一段末帧。参考图通过内置 imagegen 制作，四张图片和完整提示词集合保存在 `prompts/assets/`、`prompts/assets/cat_biscuit_image_prompts.json`。

部分动作与分镜描述存在偏差，例如寻找地上饼干屑时仍主要围着桌子活动。当前对白和情节依靠配音与字幕表达，嘴型未做严格同步；没有加入背景音乐。

画面在本机生成，配音和 ASR 使用 MiMo 云端服务。失败的单句配音尝试及修改记录已保留在批次中，未重复生成已成功的视频片段。

## 再次生成

启动 `start-comfyui-gpu.cmd` 后运行 `generate-cat-comic.cmd`。每次会建立独立批次；同批次相同输入重跑时复用成功片段和配音。完整操作、单句重配和字幕目录说明见 [配音字幕与猫咪动画](../docs/配音字幕与猫咪动画.md)。
